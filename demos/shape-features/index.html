The shape servoing loop

The Jacobian is estimated once from test motions, then used and updated at every cycle of the feedback loop.

Offline · once2. Estimate ĴEach feature change divided by its command increment gives one column of the shape Jacobian.Ĵ ≈ Δs / Δu
Online · every cycle3. Measure the errorSubtract the current feature vector from the target feature vector.e = s* − s

            Definitions of the three feature vectors
            

                
Point coordinates
The x and y coordinates of each measured point. The vector retains position, orientation and shape, so all three can be controlled, and any rigid motion of the object appears as error.
eₚ = p* − p

                
Edge vectors
The vector from each point to the next. The difference between neighbouring points cancels absolute position, so edge vectors are invariant to translation but change under rotation and bending.
e_d = d* − d

                
Curvature
The turning angle between consecutive edges. The angle difference cancels both position and orientation, so curvature is invariant to rigid motion and depends only on bending.
eκ = κ* − κ

            

        


        

            

                Takeaway
                The feature vector determines which errors the controller corrects.
                
Point coordinates retain pose and shape, edge vectors are invariant to translation, and curvature depends only on bending. The choice depends on whether the task specifies the pose of the object.
